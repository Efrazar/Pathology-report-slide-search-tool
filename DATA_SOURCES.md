# Data and model sources

Only public data and open models are used. Raw data is never committed; the scripts in
`scripts/` rebuild `data/` from these sources. Licences were checked on 23 November 2026.

| Source | Used for | Licence | Access | Credit |
|---|---|---|---|---|
| [TCGA-Reports](https://data.mendeley.com/datasets/hyg5xkznpx/1) | 9,523 OCR'd TCGA pathology reports, 32 cancer types | CC BY 4.0 | Open download | Kefeli J, Tatonetti N. TCGA-Reports: a machine-readable pathology report resource for benchmarking text-based AI models. *Patterns*, 2024. |
| [NCI Genomic Data Commons](https://portal.gdc.cancer.gov/) | Cancer type and pathologic T, N, stage per case (scoring labels) | Open-access tier, NIH data policies | Public API | The results here are based on data generated by the TCGA Research Network. |
| [PanNuke](https://warwick.ac.uk/fac/cross_fac/tia/data/pannuke) | Tissue tiles for organ classification (Track 2) | CC BY-NC-SA 4.0, research use only | Open download | Gamper J, et al. PanNuke, 2019 and 2020. |
| [H-optimus-0](https://huggingface.co/bioptimus/H-optimus-0) | Tile embeddings (Track 2) | Apache 2.0 | Gated: accept terms on Hugging Face | Bioptimus |
| [Phikon-v2](https://huggingface.co/owkin/phikon-v2) | Tile embeddings (Track 2) | Owkin non-commercial licence (full text still to review) | Open | Owkin |

The hackathon challenge data that the original module used belongs to the organizers. None of it,
nor anything derived from it, is in this repository.
