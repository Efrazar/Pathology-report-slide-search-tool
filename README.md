# Pathology report and slide search tool

Find trial-eligible patients in free-text pathology reports, and find similar tissue slides, using only public data.

This project continues my module from the DNA Forge AI x Bio Hackathon (November 2026), see [Hackathon_events](https://github.com/Efrazar/Hackathon_events). The hackathon used organizer-owned synthetic data, which is not used here. Everything in this repository is rebuilt on public datasets and open models.

Work in progress.
